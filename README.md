## Istruzioni e Note Generali

### Compilazione ed esecuzione
* **Compilazione:** eseguire il comando `make` all'interno della cartella dell'esercizio.
* **Esecuzione:** avviare il programma tramite `./nome_eseguibile`.

### Note sui file e sugli esercizi
* **File di dati (`.dat`):** alcuni file di output — in particolare quelli relativi all'**Esercizio 4** — sono stati compressi oppure omessi dalla repository per limitare lo spazio occupato.
* **Animazioni (Esercizio 4):** a causa di problemi di visualizzazione delle animazioni all'interno dei Jupyter Notebook una volta caricati su GitHub, i relativi video sono stati inseriti direttamente nei rispettivi file `README.md`.
* **Struttura dell'Esercitazione 12:** l'esercitazione è suddivisa in due parti distinte, una contenente il codice degli esercizi svolti e l'altra dedicata ai rispettivi risultati.
